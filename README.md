_PART 1: AUTO SCAN AND AUTO DELETE SEXUAL CONTENT_
The app must scan everything sexual that is posted publicly. This includes porn videos, sex videos, porn pictures, nudes, and any sexual content. 

How it works:
1. When any user uploads a Photo, Video, Reel, Status, Profile Photo, or Cover Photo, the app must scan it immediately before it goes live.
2. Use AI to detect nudity, pornography, and sexual acts.
3. If the app finds sexual content with 90 percent confidence or higher, it must DELETE it automatically everywhere in the app. It must not appear on Home, Reels, Status, Search, Profiles, or Comments.
4. Send the user a notification that says: Your post was removed. It violated MzansiTalk Community Guidelines: No sexual content allowed.
5. Save a copy of the deleted content to Admin Panel > Moderation Log so I can see it.
6. Use a 3 Strikes rule. If a user has 3 posts auto deleted for sexual content, automatically ban their account permanently.

IMPORTANT RULE: Do NOT scan or delete anything inside people's private inboxes. Do not scan Direct Messages and Group Chats. Only scan public posts, reels, status, comments, and profile pictures.

_PART 2: AUTO DELETE COPYRIGHT MUSIC_
The app must also scan all Videos and Reels for music.

How it works:
1. Only allow music that belongs to the Owner of MzansiTalk or music from the "MzansiTalk Music Library" in Admin Panel.
2. Use audio scanning to detect if a video uses music that does NOT belong to the Owner.
3. If the music does not belong to the Owner, automatically MUTE the video or DELETE the video everywhere in the app immediately.
4. Send the user a notification that says: Your video was removed. Reason: Copyrighted music. Please use music from MzansiTalk Music Library only.
5. Save it to Admin Panel > Copyright Log.

Only the Owner can add songs to the "MzansiTalk Music Library" in Admin Panel.

_PART 3: USER REPORT SYSTEM FOR ADMINS_

How it works:
1. When a user clicks Report, give them options: I do not like this, It is offensive, It is spam, It is bullying, Other.
2. When a user submits a report, do NOT delete the content automatically.
3. Send the full report to Admin Panel > Reports Inbox.
4. The Reports Inbox can ONLY be seen by Owner and Admins. Normal users cannot see it.
5. In the Reports Inbox show: Who reported it, Who posted it, The content, The reason, Date and time.
6. In the Reports Inbox, Admins must have 2 buttons: "Delete Content" and "Dismiss Report". 
7. If an Admin clicks Delete Content, delete it everywhere and notify the person who posted it. If Admin clicks Dismiss Report, do nothing.

7. If I click APPROVE AND REPOST, the content must be automatically reposted to the user's profile and feed immediately. Add this content to a "Whitelist" so it can NEVER be flagged or auto deleted again for the same reason. It must be allowed to continue and earn from ads and boosts.
8. If I click DENY APPEAL, send the user a notification that says: Your appeal was denied. Final decision. The content stays deleted.

Add these 4 new pages to the Admin Panel: Moderation Log, Copyright Log, Reports Inbox, Appeals Inbox.
